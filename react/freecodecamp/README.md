# FreeCodeCamp React

Course work and notes from the [FreeCodeCamp React curriculum](https://www.freecodecamp.org/learn/front-end-development-libraries/).

| Folder | Purpose |
|--------|---------|
| `fundamentals/` | Main Vite + React exercise app |
| `playground/` | Small experiments (`npm install` then open `index.html` or add a bundler) |
| `notes/` | Personal session notes |

## Run fundamentals

```bash
cd fundamentals
npm install
npm run dev
```
