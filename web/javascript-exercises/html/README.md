## How to open

From repo root:

```bash
# optional: simple static server
cd learning/web/javascript-exercises/html && python3 -m http.server 8080
# then visit http://localhost:8080/index.html
```

Or use VS Code / Cursor **Live Server** on `index.html`.

Always open the **Console** (F12) to see script output.
