# `js/` — core JavaScript exercises

Each `.js` file is a small revision sheet: a header comment, runnable **examples**, and `console.log` output.

## How to study

1. Open [../html/index.html](../html/index.html).
2. Pick a practice page (basics, functions-scope, control-flow, dom-practice).
3. Open DevTools → **Console** and read output while skimming the matching `.js` file.
