# secure-chat-app

Secure chat application built with Next.js (learning project).

**Location:** `gitrepos/learning/web3/practice-projects/lr-connect-chat/secure-chat-app/`

**Parent:** [../README.md](../README.md)

## Getting started

```bash
cd gitrepos/learning/web3/practice-projects/lr-connect-chat/secure-chat-app
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
